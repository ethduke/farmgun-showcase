# Farmgun

[Visit Farmgun](https://farmgun.fun/)

Farmgun is a noncustodial token launchpad for Robinhood Chain and Base.

- Launch tokens through supported launchpads.
- Explore available tickers and markets.
- View and claim supported creator fees.

Have feedback or a feature request? [Open an issue](https://github.com/ethduke/farmgun-showcase/issues).
